很多同学刚进站会问：**“我平时已经在用网页版 ChatGPT / DeepSeek 了，为什么大家现在都在装 AI Agent 和科研 Skills？”**

## 1. 网页版聊天 vs 本地 AI Agent + Skills 的本质代差

用网页版 AI 写论文，你得不停地手动复制段落、粘贴报错、上传表格、自己下载代码回本地跑；一旦论文超过几千字或涉及十几篇 PDF 文献，网页对话框很快就会遗忘上下文、甚至编造假参考文献（幻觉）。

而 **本地 AI Agent（如 Antigravity、Claude Code、Codex、Cursor）+ 科研 Skill** 的工作方式完全不同：
- **Agent 是“能直接操作你电脑文件夹的助手”**：它能直接读取你文件夹里的 30 篇 PDF 文献、直接运行 Python / R / Stata 脚本并把报错自己修好、直接生成 300 DPI 矢量 PDF 插图和排好版的 `.docx` / `.tex` 文件；
- **Skill（技能包）是“顶尖课题组沉淀下来的标准作业程序（SOP）”**：它的核心是一份结构严谨的 `SKILL.md` 规范文档与配套校验脚本，提前规定好了**怎么查真文献不造假、怎么按 Nature 色盲友好配色画图、怎么写审稿人挑不出毛病的 Rebuttal 回复信**。

装好 1 个 Agent 后，本站收录的 **500+ 款开源科研 Skills 全部免费任你按需装载**。

## 2. 四大主流科研 Agent 我该装哪一个？（只装 1 个就够了！）

你**不需要**把四个软件全装一遍，根据你的专业背景挑最顺手的 **1 个** 即可：

| 你的专业与日常习惯 | 首选推荐工具 | 推荐理由 |
| :--- | :--- | :--- |
| **零代码基础 / 跨学科本硕**<br/>（文社科、教育、法学、临床医学） | **Google Antigravity** | 可视化窗口最友好，不用死记终端命令，左边看文件夹、右边直接对话改稿。 |
| **重度论文写作 / 审稿返修 / 多任务**<br/>（全学科通用，尤其 SCI / SSCI 硕博） | **Claude Code** | 长文逻辑衔接、去 AI 腔学术润色与开源 Skills 兼容度公认最强。 |
| **数学推导 / 统计建模 / 算法复现**<br/>（数学、经管计量、物理、计算机） | **OpenAI Codex CLI** | 推理模型对公式核验、Stata/Python 回归排错与实验脚本复现极稳。 |
| **习惯在编辑器里逐行改 LaTeX / 代码**<br/>（理工科、生信、AI 顶会作者） | **Cursor** | 改哪行标绿哪行，配合 LaTeX Workshop 边改边看 PDF 预览。 |

## 3. 新手 5 分钟极速通关路线

1. **装软件**：点击左侧目录中你选定的那一款工具教程（推荐从 **Antigravity** 或 **Claude Code** 开始），花 3 分钟装好客户端；
2. **备好账号额度**：登录你已有的模型账号（若无海外信用卡或课题组需开发票报销，可直接使用下方本站自营正规渠道）；
3. **装第一套 Skills**：返回本站 **「今日榜单」**，按你的专业或点击「课题组工具包」，复制一行 `npx skills add` 命令装好即可开工！
